## Langkah 2: Install Qoder (Pilih Satu)

### Option A: Qoder Desktop (Recommended — Ada GUI)
1. Pergi ke **https://qoder.com/download**
2. Download ikut OS korang:
   - **Mac**: macOS 12+
   - **Windows**: Windows 10+
   - **Linux**: .deb / .rpm
3. Install & buka app

### Option B: Qoder CLI (Terminal je)
```bash
# Mac / Linux
curl -fsSL https://qoder.com/install | bash

# Windows PowerShell
irm https://qoder.com/install.ps1 | iex
```
Lepas install, login:
```bash
qodercli login
```
(akan buka browser untuk authentication)

### Option C: JetBrains Plugin
1. Buka JetBrains IDE (IntelliJ, VS Code, etc.)
2. Pergi **Settings → Plugins → Marketplace**
3. Search **"Qoder"**
4. Install plugin "Qoder – Think Deeper, Build Better"
5. Login dari dalam IDE
