## Problems Solved

### 1. Google OAuth Blocked (Datacenter IP)
- **Problem:** Google rejects login from `/v3/signin/rejected` on Alibaba Cloud IPs
- **Solution:** Use email/password registration instead of Google OAuth
- **Lesson:** Even Puppeteer+stealth can't bypass Google's datacenter IP detection for all OAuth clients

### 2. Form Submission Not Working
- **Problem:** `agent-browser fill` + click button doesn't trigger SPA form submission
- **Solution:** Use `click` on field → `type` text → `focus` password field → `press Enter`
- **Lesson:** SPA frameworks (React/Next.js) need proper keyboard events, not just value setting

### 3. Verification Emails Not Arriving
- **Problem:** After multiple registrations, mail.tm stopped receiving emails from TokenHarbor
- **Root cause:** mail.tm account was created AFTER registration, so email bounced
- **Solution:** Create mail.tm account FIRST, then register on TokenHarbor
- **Lesson:** Always pre-create the temp email account before using it for registration

### 4. Gift Claim Silently Failing
- **Problem:** Script said "Gift claimed" but balance remained $0
- **Root cause:** Claim button click didn't actually trigger (SPA rendering delay)
- **Solution:** Manual claim via browser with proper wait times
- **Lesson:** Always verify balance after claim, don't trust button click success
