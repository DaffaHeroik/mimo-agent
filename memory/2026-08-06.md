## Key Findings

- Auth: Bearer token (user token, not machine token)
- User token encrypted with WASM in `~/.qoder/.auth/user`
- Desktop app can claim via UI: Usage panel → "Claim Now"
- Machine token in `~/.config/Qoder/SharedClientCache/cache/machine_token.json`
