## Technical Lessons
1. **Google OAuth from datacenter IP WORKS** for some sites (TokenHarbor, Manus)
2. **Cloudflare Turnstile** blocks direct form submission from datacenter IP
3. **Cookie consent** must be handled before clicking OAuth buttons
4. **Google consent flow** varies: "Lanjutkan" (ID), "Continue" (EN), "Izinkan" (ID for permissions)
5. **Email verification is separate** from OAuth — still need to check inbox and click link
6. **Free models on TokenHarbor** need explicit consent toggle in dashboard
7. **Manus API** is task-based, not chat-based — uses task.sendMessage pattern
8. **Puppeteer frame detachment** after Next.js Server Actions — use separate browser launches
