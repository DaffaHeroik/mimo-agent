## Key Discoveries

### 1. Puppeteer + stealth > Playwright
- Playwright fingerprinting → Google rejects (`/v3/signin/rejected`)
- Puppeteer + puppeteer-extra-plugin-stealth → Google accepts
- Same server, same IP, different result based on browser automation framework

### 2. Google Blocks All Datacenter IPs
- Tested 90+ free SOCKS5 proxies from multiple sources
- ALL are datacenter/VPS IPs (Contabo, Aeza, Rostelecom, etc.)
- Google has database of datacenter IP ranges and blocks them all
- Need TRUE residential IP (home WiFi, mobile data) to bypass

### 3. Ollama Radar Challenge
- Ollama has its own anti-bot system (`radar-challenge`)
- Intermittent: some accounts pass, some get blocked
- Not related to Google — it's Ollama's own security

### 4. Key Extraction
- Ollama API keys are 32-char hex strings (not `oll-` prefix)
- Need regex: `/([a-f0-9]{32})/` not just `/(oll-[a-zA-Z0-9_-]{20,})/`
